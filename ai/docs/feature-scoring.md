# Cold Feature 점수 계산

`copenhagen_fds.scoring.score_feature(raw, reference)`는 수집된 Raw Feature 하나와
선택된 기준 파라미터 하나로 `AnomalyScore`를 반환한다. 기준 선택은
[Cold 기준 선택](baseline-selection.md)에서 수행한다.

## 변환 계약

계산 버전은 `cold-distance-linear-v1`, 점수 단위는 `BEHAVIOR_ANOMALY_0_100`이다.
입력값을 `x`, 기준을 `center`, 포화 거리를 `scale`이라 할 때 다음 식을 사용한다.

| method | 거리 d | 해석 |
|---|---|---|
| `UPPER_DISTANCE` | `max(x - center, 0)` | 기준 초과만 평가 |
| `ABSOLUTE_DISTANCE` | `abs(x - center)` | 기준 양쪽 이탈을 평가 |
| `CIRCULAR_DISTANCE` | `min(abs(x-center) % period, period - (abs(x-center) % period))` | 주기상 가장 가까운 거리 |

`score = 100 × min(d / scale, 1)`로 변환한다. 거리가 0이면 0점,
`scale / 2`이면 50점, `scale` 이상이면 100점이다. 시간은 24시간,
요일은 월요일 0부터 일요일 6까지 7일 주기로 계산한다. 일요일과 월요일의 거리는 1일이다.

`center`와 `scale`은 버전이 명시된 기준에서 제공한다. `scale`은 같은 원시 단위의
**100점 도달 거리**이며 자동 추정한 표준편차가 아니다. 빈도는 해당 시간 창의 건수,
금액은 통화 최소 단위, 시간은 시간, 요일은 일 단위다. 수식 변경 시 계산 버전을 바꾼다.

이 변환은 이탈 정도를 유계 점수로 표시하기 위한 초기 정책이다. 논문 성능을 재현한
학습 모델이나 보정된 사기 확률이 아니다. 금액 50점과 빈도 50점은 각각 설정한 거리의
절반에 도달했다는 뜻이며 동등한 위험을 보장하지 않는다. 0점도 정상 거래의 증명이 아니다.
초기 정책의 파라미터, 단봉형 시간 기준, 주기적 요일 거리는 실제 이용자 분포에 적합한지
별도 검증이 필요하다. 점수 가중합·위험등급·개인 프로필 학습은 이 함수에서 수행하지 않는다.

## 수치와 누락 처리

- 입력은 `AVAILABLE`이어야 한다. 미수집·이력 부족·적용 불가는 점수 0으로 대체하지 않고
  호출 오류로 반환한다. 평가 단위의 상태 매핑에서 이러한 입력을 먼저 처리해야 한다.
- Feature ID·단위·시간 창·주기·파라미터 유효성을 검증한다.
- 정수 입력과 파라미터의 십진 문자열을 유리수로 계산하고, 0~100으로 제한한 뒤
  JSON 숫자용 실수로 변환한다. 큰 금액·작은 scale도 중간 계산에서 무한대가 되지 않는다.
- 양수 점수가 실수 표현 한계로 0이 되는 경우 최소 양의 실수로 보존한다.
- 외부 API, 현재 시각, 난수, 환경 변수, 학습 상태를 사용하지 않는다.

## 직접 확인

가상환경을 활성화하고 `ai` 디렉터리에서 실행한다.

```bash
python -m pytest tests/test_feature_scoring.py -v --tb=short
```

수기로 확인할 대표값: 금액 `center=10000, scale=20000, UPPER_DISTANCE`에서
10,000원 → 0점, 20,000원 → 50점, 30,000원 이상 → 100점이다.
10분 구매 빈도 `center=2, scale=8`에서 6건 → 50점이다.
시간 `center=0, scale=12`에서 23시 → 약 8.3333점, 12시 → 100점이다.
