# 보유 데이터의 사용 범위

`ai/data/fraud_model_features_erd_common.csv`는 구조를 점검할 수 있는 **학습 후보 Feature 표**다. 최종 학습 데이터로 확정하지 않는다. 원본·생성 과정·라벨 근거와 시간순 이력 계산을 재현할 증거가 없으므로, 현재 사용할 수 있는 범위는 로컬 집계 점검과 합성 시나리오 설계를 위한 열 구조 참고다. 상세 근거와 재현 방법은 [데이터 적합성 점검](dataset-suitability.md)에 기록한다.

## 실제 파일에서 확인한 수치

아래 수치는 파일 SHA-256 `d59aa0c2c3f07e26f3712d33b3dd659bb532871ae8a8fff517ffe511347b4378`에 대한 결과다. 파일이 달라지면 다시 점검해야 한다.

| 항목 | 결과 |
|---|---:|
| 행 수 | 100,000 |
| 입력 Feature / 전체 열 | 27 / 28 |
| 라벨 | `is_fraud` |
| 정상 / Fraud 라벨 | 91,789 / 8,211 |
| 전체 행 중 Fraud 라벨 비율 | 8.211% |
| 빈 셀 / 비수치 셀 / NaN·Infinity | 모두 0 |
| `user_account_age_days` 음수 | **0** |
| 기존 Feature 명세의 야간 계산식과 불일치 | **4,132행** |

이 문서의 이전 버전에 있던 계정 연령 음수 **16,606건** 주장은 현재 파일에서 재현되지 않는다. 음수 0건이 어떤 보정으로 만들어졌는지는 생성 코드와 원본 이력이 없어 확인할 수 없다. 원시 시각을 복원하거나 값을 추가 보정하지 않는다.

야간 불일치는 `fraud_feature_spec.csv`에 적힌 `kst_hour`의 22~23시 또는 0~5시라는 정의를 적용한 결과다. 실제 파일이 다른 기준으로 생성되었는지 확인되지 않았으므로 데이터를 임의로 다시 쓰지 않는다.

## 사용 판단

| 대상·용도 | 판단 | 근거 |
|---|---|---|
| 보유 Feature CSV의 스키마·집계 확인 | 가능 | 로컬 파일에서 원시 행을 공개하지 않고 재현 가능 |
| Feature 이름을 참고한 별도 합성 시나리오 설계 | 가능 | 명시한 시나리오를 검증하는 용도이며 실제 탐지 정확도를 증명하지 않음 |
| 모델 학습 데이터로 최종 채택 | 보류 | 출처·사용 조건·라벨 원천·생성 코드가 확인되지 않음 |
| 개인·집단 프로필 생성과 시간순 재생 평가 | 보류 | 사용자·거래 식별자, 사건 시각·이용 가능 시각이 없음 |
| 실거래 사기 탐지 성능 또는 Cold Start 성능 주장 | 보류 | 정답·분할·미래 정보 배제의 근거가 부족함 |
| 원시 데이터의 Git 등록·재배포 | 하지 않음 | 현재 점검은 로컬 메타데이터·집계만 공유함 |

이전 [공개 데이터 비교 문서](fraud_dataset_comparison.md)는 후보 선정 당시의 검토 기록이다. 해당 문서가 언급하는 `Fraud_Data.csv`, `fraud_model_features.csv`는 현재 `ai/`에서 확인되지 않는다. 공개 후보의 이름이나 열의 유사성만으로 현재 파일의 출처·권리·계산식 일치를 증명할 수 없다. 그 문서의 최종 학습 선정 결론보다 이 문서와 적합성 점검의 현재 사용 범위를 적용한다.

## 학습 후보를 다시 검토할 조건

- 원본 출처·버전·해시, 파일 간 변환 과정과 실제 적용되는 사용 조건을 확인한다.
- `is_fraud`가 실제 판정인지 합성 규칙인지와 라벨을 알게 된 시점을 확인한다.
- BE가 제공하는 이력으로 같은 Feature를 같은 정의로 계산할 수 있는지 검증한다.
- 사용자·거래 ID 및 시간 정보를 보존한 원시 이력으로 현재 거래와 미래 정보를 제외해 다시 집계한다.
- 시간 순서를 보존한 학습·검증·평가 분할을 구성하고, 사용자 중복과 라벨 지연을 고려한다.

무작위 Stratified Split만으로 시간 누수 문제를 해결했다고 판단하지 않는다. 현재 27개 수치 입력에 사용자 ID가 필요하지 않더라도, 프로필 생성·분할·중복 확인에는 별도의 식별 정보와 시간 정보가 필요하다. 이 작업에서는 학습, 샘플링, 값 보정, 다른 서비스 코드 변경을 수행하지 않는다.
