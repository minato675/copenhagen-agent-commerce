# 학습 반영 정책의 입력과 기준

`PolicyObservation`은 기존 `LearningSample`과 그 판정에 사용한 `LearningFeedback`을
연결한다. 기존 학습 표본에는 확인 ID만 있고 실제 확인 가용 시각은 없으므로, 정책에는
선택된 확인 근거를 함께 전달해야 한다. 이미 알려진 근거는 구매·주문 버전·확인 ID·
분류·검증 상태가 원래 학습 판정과 일치해야 한다.

미래 확인 근거는 판단과 입력 해시 계산 전에 제거한다. 원래 표본이 정상이라고 주장해도
이용 가능한 정상 확인 근거가 없으면 MISSING_REVIEW_EVIDENCE로 보류한다.
검증된 근거의 진위와 접근 권한을 보장하는 책임은 호출자에게 있다.

`ProfilePolicyConfig`의 초기값은 프로젝트 검증용 가정이며 운영 성능으로 보정된 값이 아니다.

| 설정 | 초기값 | 의미 |
|---|---|---|
| max_admissions_per_user_day | 10 | 사용자별 한국 시간 날짜당 반영 상한 |
| min_reference_samples | 5 | 피처별 기준 비교에 필요한 정상 반영 표본 수 |
| deviation_ratio | 3.0 | 중앙값 기준 상·하방 변화 범위 |
| amount_floor_minor / count_floor | 1 / 1 | 영값·고정값 기준에서 사용할 최소 절대 차이 |
| hour_tolerance / weekday_tolerance | 2 / 0 | 원형 시간대·요일에서 이미 관측된 값과 허용할 거리 |
| adaptation_window_days | 28 | 비슷한 정상 변화의 근거를 찾는 구매 기간 |
| adaptation_min_samples / adaptation_min_days | 5 / 3 | 서로 다른 구매 수와 한국 시간 구매 날짜 수 |
| similarity_ratio | 1.5 | 변화 근거로 묶을 수치 피처 값의 유사 범위 |

수치 피처의 허용 범위는 `min(중앙값/비율, 중앙값-절대차이)`부터
`max(중앙값*비율, 중앙값+절대차이)`다. 시간대·요일은 선형 평균으로 비교하지 않고
관측된 원형 구간과의 가장 짧은 거리를 사용한다. 예를 들어 23시와 0시는 1시간 차이다.

비교 기준은 해당 판단 시점까지 이미 반영한 정상 표본으로 만든다. 피처의 장기 기준에
충분한 표본이 있고 장기·최근 기준 모두에 맞지 않을 때만 급격한 변화로 표시한다.
최근 기준이 충분하고 새 패턴과 맞으면 장기 기준과 다르더라도 반영할 수 있다.
결측이나 기준 부족을 이상 점수로 바꾸지 않는다.

정책 판단에는 사용한 설정 해시·정책 버전, 근거 확인, 최근/장기 시작 시각·표본 수·
중앙값 또는 원형 거리, 기준 표본/피처 해시, 변화 지지 구매 ID와 날짜 수를 남긴다.
이는 학습 반영 근거이며 결제 차단 여부나 사기 확률을 뜻하지 않는다.

검증: `python -m pytest tests/learning/policy/test_contracts_and_reference.py -v --tb=short`
