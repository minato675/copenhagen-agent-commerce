# 장바구니 QA 개선 (502·503)

기존 채팅 중심 흐름을 유지합니다. 위젯은 선택 정보를 저장하고 모델 컨텍스트에 참조를 전달한 뒤 자연어 요청을 한 번 보냅니다. 실제 변경은 모델이 apply_cart_changes를 호출할 때 수행됩니다.

## 사용자 동작

- 수량 입력과 삭제 선택은 로컬 초안입니다. 원래 값으로 돌아가면 변경에서 제외됩니다.
- 삭제 취소로 복구할 수 있습니다. 유효하지 않은 수량, 변경 없음, 요청 전달 후에는 적용할 수 없습니다.
- 변경 예정 상품 금액은 배송비를 포함하지 않는 미리보기이며 확정 금액을 대체하지 않습니다.
- 변경사항이 남아 있으면 결제 요청이 비활성화됩니다. 적용 후 새 장바구니에서 결제를 이어갑니다.

## 서버 처리 및 재시도

- 최대 30개 항목을 입력 순서대로 처리하며 동일 항목 중복 입력을 거절합니다.
- Core가 반환한 버전을 다음 변경에 사용합니다. 버전을 추측하거나 동일 버전으로 병렬 변경하지 않습니다.
- 루트 멱등키와 항목 순번으로 안정적인 하위 키를 생성합니다. 동일 전체 요청을 재전달하면 Core의 사용자별 저장 응답을 사용합니다. Core 재시도 보존 기간(24시간) 내에서만 같은 요청을 확인합니다.
- 전체 트랜잭션은 아닙니다. 실패한 항목에서 멈추고 appliedItemIds, stoppedIndex, unconfirmedCount를 구분합니다. UNKNOWN은 성공으로 간주하지 않습니다.
- 성공했지만 장바구니 응답을 해석하지 못하면 추가 변경을 중단하고 현재 장바구니를 조회합니다. 성공한 항목을 새 키로 재실행하지 않습니다.
- 버전 충돌은 최신 장바구니를 표시한 뒤 사용자가 미처리 항목을 다시 선택하도록 합니다. 원래 요청의 순서·본문을 임의로 바꾸어 재실행하지 않습니다.
- 마지막에 display_cart를 한 번 호출하도록 도구와 모델 컨텍스트에 안내합니다. 실제 호스트가 이 지시를 수행하는지는 배포 후 검증해야 합니다.

## 검증

로컬 UI 자동 테스트, MCP 테스트·checkstyle, fixture 미리보기에서 두 상품의 수량 변경·삭제를 한 번의 메시지로 전달하고 최종 장바구니 한 장을 확인했습니다. 운영 장바구니나 결제는 사용하지 않았습니다.

배포 후 ChatGPT와 Claude에서 같은 수량/원복/잘못된 수량/여러 수량과 삭제/연속 클릭/부분 실패/최종 카드 한 번 표시를 확인합니다. 새 도구를 사용하려면 MCP 이미지를 배포하고 호스트의 도구 목록을 새로고침해야 합니다.

## 이전 카드와 내부 정보 (504)

- 요청을 보낸 카드는 큰 테두리·제목·설명과 최신 장바구니 버튼으로 후속 확인 경로를 제공합니다. 전송 완료를 실제 변경 성공으로 표현하지 않습니다.
- 장바구니 변경 및 구매 요청 전 기존 prepare_cart 응답의 버전을 확인합니다. 다른 요청으로 버전이 달라졌으면 최신 버전으로 임의 덮어쓰지 않고 다시 선택하게 합니다.
- 구매 카드의 UUID 표시는 제거하며 내부 호출 인자와 인증·멱등 처리는 유지합니다. 자연어 답변에서도 내부 번호와 상태 코드를 나열하지 않도록 도구 설명을 보강합니다.
- Claude/ChatGPT가 제공하는 도구 승인창·입력 JSON·보안 경고는 호스트 영역입니다. 이 변경으로 숨기거나 우회하지 않습니다.
- 상세 상품 이미지 최대 폭을 320px로 제한하고 내용 높이의 소수점 반올림 여유를 포함해 호스트에 알립니다. 스크롤을 강제로 숨겨 내용을 자르지 않습니다. 호스트 자체 최대 높이 제한은 별도입니다.

## 영수증형 장바구니 추가 피드백

가로로 넘기는 상품 카드를 영수증형 목록으로 변경했습니다. 각 행의 좌측에 작은 정사각형 이미지, 상품·옵션·판매처 정보, 금액과 수량·삭제 선택을 표시합니다. 좁은 화면에서는 수량과 금액을 행의 두 번째 줄에 배치해 가로 스크롤을 만들지 않습니다. 기존 초안·일괄 적용·결제 차단 로직은 그대로 사용합니다.

상품명 아래 현재 옵션 표시를 클릭하면 실제 상품 상세를 조회해 해당 위치에 선택 메뉴를 표시합니다. 옵션을 임의 생성하지 않으며 품절 옵션을 비활성화합니다. 단일 옵션은 변경 불가 안내를 제공합니다. 선택 옵션의 허용 수량과 단가를 초안 검증·미리보기에 사용하며 실제 변경은 일괄 적용 시에만 수행합니다.
