### 1.2 배경 (Background)

온라인 상거래의 성장으로 소비자가 이용할 수 있는 이커머스 플랫폼과 상품 선택지는 크게 증가했다.

하지만 소비자는 원하는 상품을 구매하기 위해 여러 판매처를 직접 방문하여 가격, 재고, 옵션, 배송 조건 등을 비교해야 하며, 플랫폼마다 다른 검색·장바구니·결제 절차를 반복해서 수행해야 한다.

최근에는 ChatGPT와 같은 LLM 기반 챗봇을 활용하여 상품을 탐색하고 구매 정보를 얻는 방식이 확산되고 있다. 그러나 기존 LLM 기반 쇼핑 경험은 주로 상품 추천이나 판매처 안내에 머물며, 제공되는 상품 정보가 실제 가격·재고·옵션과 다를 가능성도 존재한다.

결국 사용자는 추천을 받은 이후에도 실제 쇼핑몰에 접속하여 상품 정보를 다시 확인하고, 장바구니 구성과 결제를 직접 수행해야 한다.

### 1.3 목적 / 목표 (Goal)

본 프로젝트는 **상품 탐색부터 장바구니 구성, 구매 및 결제까지 이어지는 쇼핑 과정을 AI 에이전트를 통해 자동화**하는 것을 목표로 한다.

단, AI의 판단만으로 결제가 이루어지지 않도록 사용자의 구매 의도와 실제 장바구니 및 결제 내용을 검증하고, 사용자의 명시적인 승인과 최종 인증을 거친 경우에만 결제를 수행한다.

이를 통해 반복적인 쇼핑 과정은 AI에게 위임하면서도 중요한 구매 결정과 결제 권한은 사용자에게 유지하는 **신뢰 가능한 에이전트 기반 쇼핑 경험**을 제공한다.

## 2. 문제 정의 (Problem Definition)

현재 온라인 쇼핑 및 LLM 기반 상품 탐색에는 다음과 같은 문제가 존재한다.

- 여러 쇼핑몰을 직접 방문하여 가격, 재고, 옵션, 배송 조건 등을 비교해야 한다.
- 쇼핑몰마다 검색, 장바구니, 결제 방식이 달라 반복적인 조작이 필요하다.
- 여러 판매처를 비교하는 과정에서 더 나은 가격이나 구매 조건을 놓치기 쉽다.
- 기존 LLM 기반 서비스는 상품 탐색과 추천은 지원하지만 실제 장바구니 반영이나 구매 실행까지 이어지지 않는 경우가 많다.
- LLM이 제공하는 상품 링크, 가격, 재고 등의 정보가 실제 쇼핑몰의 최신 정보와 다를 수 있다.
- 상품을 추천받더라도 사용자가 다시 쇼핑몰에 접속하여 실제 상품 정보를 확인하고 구매 절차를 직접 수행해야 한다.

본 프로젝트는 이러한 **상품 탐색과 실제 구매 실행 사이의 단절**을 해결하고자 한다.

## 4. 핵심 컨셉 (Core Concept)

### 4.1 한 줄 정의

> **실행은 AI에게, 승인은 사용자에게**

사용자는 대화형 인터페이스를 통해 원하는 상품과 구매 조건을 자연어로 요청한다.

AI 에이전트는 사용자의 요청을 바탕으로 여러 쇼핑몰에서 상품을 탐색하고 비교하여 적합한 상품을 추천하며, 사용자가 선택한 상품을 실제 구매 가능한 상태까지 준비한다.

반복적인 상품 탐색과 장바구니 구성은 AI가 수행하지만, **구매 내용 확인과 결제 최종 승인 및 인증은 반드시 사용자가 직접 수행한다.**

전체적인 사용자 경험은 다음과 같다.

**자연어 요청 → 상품 탐색·비교 → 상품 선택 → 장바구니 구성 → 구매 내용 확인 → 사용자 승인 → 사용자 인증 → 결제**

### 4.2 핵심 프로토콜 역할

프로젝트에서는 각 프로토콜의 역할을 다음과 같이 구분한다.

- **UCP (Universal Commerce Protocol)**  
  여러 쇼핑몰의 상품, 가격, 재고 등 커머스 정보를 조회하고 실제 구매 가능한 오퍼를 구성하는 역할을 담당한다.

- **AP2 (Agent Payments Protocol)**  
  사용자의 구매 의도와 실제 구매 내용을 연결하고, Intent Mandate → Cart Mandate → Payment Mandate로 이어지는 절차를 통해 사용자 의도 확인 및 결제 승인을 담당한다.

- **MCP (Model Context Protocol)**  
  AI 에이전트가 외부 도구 및 데이터 소스와 연결되어 필요한 작업을 실행할 수 있도록 한다.

## 5. 밸류 프로포지션 / 차별점 (Value Proposition)

본 프로젝트는 단순히 상품을 추천하는 AI를 넘어 **실제 구매 과정까지 실행할 수 있는 AI 에이전트**를 지향한다.

동시에 AI에게 결제 권한 전체를 위임하지 않고 사용자의 확인과 인증을 결제 과정에 포함하여 자동화의 편의성과 구매 안전성을 함께 확보한다.

핵심 가치는 다음과 같다.

- **탐색에서 실행까지 연결**  
  상품 추천에서 끝나지 않고 실제 장바구니 구성과 구매 준비까지 AI가 수행한다.

- **최신 커머스 정보 기반 구매**  
  실제 쇼핑몰의 상품, 가격, 재고 등의 정보를 기반으로 구매 가능한 상품을 탐색한다.

- **사용자 통제권 유지**  
  AI가 구매 과정을 대신 수행하더라도 최종 구매 여부와 결제 승인은 사용자가 결정한다.

- **검증 가능한 결제 과정**  
  사용자의 구매 의도와 실제 장바구니 및 결제 내용을 연결하여 의도하지 않은 구매나 결제가 이루어지는 것을 방지한다.

## 6. 핵심 설계 원칙 (Core Principles)

### 6.1 실행까지 자동화

상품 탐색, 비교, 추천 및 장바구니 구성과 같은 반복적인 쇼핑 작업은 AI 에이전트가 수행하여 사용자의 개입을 최소화한다.

### 6.2 승인은 사용자에게

결제 최종 승인은 반드시 사용자가 직접 수행하며, 비밀번호 또는 생체인증 등을 통해 사용자의 실제 승인을 확인한다.

### 6.3 확장 가능한 구조

쇼핑몰별 연동 로직을 독립적으로 확장할 수 있도록 설계하여 새로운 쇼핑몰을 추가할 수 있도록 한다.

장기적으로는 동일한 구조를 쇼핑뿐 아니라 티켓, 부킹, 배달 등 다른 거래 플랫폼으로 확장할 수 있도록 한다.

## 7. 범위 (Scope)

### 7.1 In Scope

현재 프로젝트에서 구현하는 범위는 다음과 같다.

- 사용자의 자연어 요청 기반 상품 탐색 및 추천
- 여러 쇼핑몰의 상품 비교
- 추천 상품 선택 및 조건 조정
- 선택 상품의 실제 쇼핑몰 장바구니 반영
- 상품 및 장바구니 정보 확인
- 사용자의 구매 내용 확인 및 승인
- 비밀번호 또는 생체인증을 통한 결제 최종 승인
- 승인된 결제의 실행 및 결과 제공

### 7.2 Out of Scope

다음 기능은 현재 프로젝트의 핵심 구현 범위에서 제외하며 향후 확장 대상으로 고려한다.

- 마이데이터 연동을 통한 사용자 보유 카드별 혜택 비교 및 추천
- 사전 연동된 쇼핑몰에서 신규 카드 등록 없이 기존 인증 결제수단을 활용하는 기능
- 티켓, 부킹, 배달 등 쇼핑몰 외 거래 플랫폼 연동
