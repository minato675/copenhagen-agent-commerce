## 보존 방식

원본을 squash하거나 rebase하지 않고, 원본 기본 브랜치를 부모로 갖는 병합 커밋으로 연결했습니다.
원본 브랜치·태그와 PR 참조도 `history/<원본 저장소>/...` 이름으로 보존했습니다.
이전 경로와 내용은 보존 브랜치를 선택해 확인할 수 있습니다.
기본 브랜치의 파일은 통합 위치에서 Git blob ID와 파일 모드를 원본과 비교했습니다.
문서를 새 경로에 맞춰 고친 경우 원문을 별도 경로에 보관하고 [기계 판독 기록](REPOSITORY_MERGE.json)에 연결했습니다.

이번 작업은 저장소·문서·이력 통합입니다. 기존 실험을 다시 학습하거나 전체 서비스·실기 검증을 새로 수행한 결과는 아닙니다.
원본 저장소 삭제는 GitHub에 올린 결과를 다시 내려받아 모든 원본 커밋·파일·참조가 보존된 것을 확인한 뒤 진행합니다.
원본 미러 저장소·bundle·저장소 메타데이터는 작업 PC에 별도 백업했습니다.
