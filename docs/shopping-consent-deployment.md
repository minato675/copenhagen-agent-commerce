# ChatGPT 쇼핑 연결 동의 권한 보완

연결 서비스가 일부 권한만 요청하더라도 등록된 허용 권한에
`catalog:read`, `cart:read`, `cart:write`, `purchase:handoff`가 모두 있으면 네 권한을 동의 화면에 표시한다.
로그인과 동의가 완료된 뒤에만 해당 권한으로 연결을 생성한다.
ChatGPT와 Claude 등 전체 쇼핑 권한이 등록된 서비스의 모든 사용자에게 동일하게 적용한다.
허용 권한이 부족한 클라이언트의 권한은 확장하지 않는다.
구매 요청 권한은 앱에 구매 요청을 전달하는 권한이며 결제 승인을 대신하지 않는다.

## 배포 후 확인

1. 이 변경이 포함된 Core 이미지를 배포한다. DB 마이그레이션은 없다.
2. ChatGPT에서 새 계정 연결 절차를 시작한다. 이미 열린 동의 페이지는 다시 사용하지 않는다.
3. Core 동의 화면에 상품 조회, 장바구니 조회, 장바구니 변경, 구매 요청 권한이 표시되는지 확인한다.
4. 사용할 계정으로 로그인하고 동의한다.
5. 새 연결의 `granted_scopes`에 네 권한이 있는지 확인하고 검색과 장바구니 담기를 확인한다.

기존 연결 및 이미 생성된 동의 요청에는 소급 적용하지 않는다.
동의 화면에 상품 조회만 표시된다면 배포 이미지와 해당 클라이언트의 `allowed_scopes`를 확인한다.
이 수정은 권한 부족으로 인한 재연결을 대상으로 하며, 다른 토큰 검증 오류까지 해결했다고 보장하지 않는다.

검증: AuthorizeConsentServiceTest 19개 및 Core checkstyle 통과.
