## 수정 범위

참조가 없으면 resolve_widget_action의 intent에 사용자 요청 문장 전체를 전달한다.
같은 계정·연결에서 정확히 일치하는 저장 요청 하나만 조회한다. 여러 일치는 거부한다.
15분 TTL, 원래 인자·멱등키와 대상 도구 권한 검사를 유지한다. 조회는 변경을 실행하지 않는다.
모델은 원래 변경 도구의 응답을 확인한 뒤 결과를 알려야 한다.
이는 호스트의 실제 안전 거부를 우회하는 경로가 아니다.

수량·삭제 초안은 같은 cartId/version에서만 복원한다. 옵션 가격·판매 가능 여부는 저장된 초안으로 신뢰하지 않는다.
전달한 요청의 옵션 포함 전체 인자는 기존 pending intent에 보존한다. 불명확한 결과를 자동 재실행하지 않는다.
