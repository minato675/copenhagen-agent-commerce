# S15P21A207-473 검증 및 배포 후 측정

## 기준 표본
2026-09-21 샌드위치 요청의 서버 로그: prepare_cart 1회, search_products 5회,
display_products 3회, get_product_detail 3회, add_cart_item 3회 = 15회.
첫 도구 실행부터 마지막 담기 완료까지 33.125초, 도구 실행 합계 362ms.
호출 사이 시간을 모두 모델 추론 시간으로 해석하지 않는다.

## 변경 흐름
prepare_cart → search_products_batch(최대 8조건) → display_search_batch(결과 재사용)
→ get_product_details_batch(선택한 최대 8상품) → 기존 add_cart_item 순차 호출.
같은 5검색·3상세·3담기 표본은 모델이 새 도구를 사용할 경우 7회 호출로 구성 가능하다.
이는 호출 구조 비교이며 실측 성능 향상 수치가 아니다.
변경 도구를 억지로 묶어 cartVersion/멱등성/부분 성공 복구를 훼손하지 않는다.

## 검증
- 서버 테스트: 검색 결과 재사용, 소유자/연결 격리, 5분 만료, 입력 상한, 부분 실패, 인증 실패 전파.
- 기존 MCP 전송 계층 도구 목록·메타데이터 검사.
- UI 빈/실패 묶음 카드 숨김과 일부 성공 표시 검사.

## 운영 확인
MCP 배포 후 연결 도구를 새로고침한다. 같은 요청과 모델로 전송/첫 카드/최종 응답 시간을 기록한다.
서버 MCP timing 로그의 호출 수와 elapsedMs를 함께 비교한다.
참조는 사용자·연결별 메모리 저장이며 5분 뒤 또는 재시작 시 만료된다.
다중 MCP 인스턴스 배포는 공유 저장소 또는 세션 고정이 필요하다.
실제 ChatGPT 전체 경과 시간은 배포 전 로컬 테스트로 검증하지 않았다.
